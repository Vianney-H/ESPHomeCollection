## Tâches

1. **Extraire les spécifications hardware** depuis la page LCD Wiki déjà fetchée
   - Paramètres ESP32-S3 (CPU, mémoire, WiFi, Bluetooth)
   - Paramètres d'écran (résolution 240x320, ILI9341V, IPS TFT)
   - Paramètres tactile (FT6336G, I2C)
   - Dimensions, poids, tension, consommation

2. **Cartographie complète des pins** (tableau reference)
   - LCD : IO10 (CS), IO46 (DC), IO12 (CLK), IO11 (MOSI), IO13 (MISO), RST (partagé), IO45 (Backlight)
   - Touch : IO16 (SDA), IO15 (SCL), IO18 (RST), IO17 (INT)
   - RGB LED : IO42 (WS2812B)
   - MicroSD : IO38 (CLK), IO40 (CMD), IO39/41/48/47 (DATA0-3)
   - Audio : IO1 (AMP enable, active low), IO4 (MCLK), IO5 (BCLK), IO8 (DOUT), IO7 (LRCLK), IO6 (DIN)
   - Key : IO0 (BOOT), EN (RESET)
   - UART : IO43 (RXD0), IO44 (TXD0)
   - Battery : IO9 (ADC)
   - Expand : IO2, IO3, IO14, IO21
   - I2C : IO16 (SDA), IO15 (SCL)

3. **Section composants ESPHome** avec exemples YAML
   - `esp32` + `psram` (octal 80MHz)
   - `spi` (ILI9341)
   - `i2c` (FT6336)
   - `output` + `light` (backlight IO45)
   - `display` (ili9xxx, ILI9341)
   - `touchscreen` (ft63x6)
   - `i2s_audio` + `audio_dac` (ES8311) + `microphone` + `speaker`
   - `switch` (audio amp IO1, inverted)
   - `binary_sensor` (touch)
   - `lvgl` (rotation, widgets, styles)
   - `voice_assistant`
   - `camera` (optionnel, pour caméras IP via http_request/online_image)

4. **Configuration complète d'exemple** (YAML fusionné, commenté)

5. **Notes et pièges**
   - Inversion couleurs ILI9341
   - Rotation LVGL 90°
   - Backlight actif haut
   - AMP enable actif bas
   - Partage RST LCD/ESP32
   - Partage I2C tactile
   - PSRAM octal obligatoire pour LVGL
